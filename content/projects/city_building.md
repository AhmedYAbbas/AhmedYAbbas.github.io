# City Building

A work-in-progress UE5.3 city-building prototype, recreating [The Game Dev Channel's City Building series](https://www.youtube.com/playlist?list=PLFYGCCDpMHmHJwhIRY6qNumAts--W8bTy) in C++ instead of Blueprints. Features a grid-based placement system for roads and buildings with adjacency validation and preview materials, a day/night cycle with adjustable time speed, a currency system, and randomized citizen generation (mesh, gender, name, age, education, health).
