Text Invaders

Text Invaders (GitHub) A classic text-based space invaders game written entirely in C++ using PDCurses. Building the Project The project only supports x86 Windows for now! Clone the repository. Open Space Invaders.sln and make sure the platform is x86 then hit F5. An error will appear that pdcurses.dll is missing. Extract pdcurses.zip and copy pdcurses.dll from the extracted folder. Navigate to the bin/Win32/Your-Configuration/ folder and paste the dll. Open Space Invaders.sln and hit F5 again. Features Aliens in different rows have different scores. Mystery UFO. Destructable shields. Aliens move sideways and when they hit the sides they move one row down. Aliens move faster when destroyed or each time they move downwards. Each level, aliens start one row lower than the previous level. If the aliens reach the bottom of the screen, the game ends. Aliens drop bombs (max 3 bombs), and the player could only 1 missile at a time (they do not collide). Player and aliens animations. Intro, gameplay, gameover, and highscore screens. Timefall

Timefall (flagship) Timefall is a game engine built from scratch in C++, originally inspired by The Cherno’s Game Engine Series and developed well beyond it since. The goal: a Windows-first engine with AAA-grade rendering quality, an editor workflow comparable to commercial tools, and a C#-scripted gameplay layer. Renderer A forward 3D PBR pipeline: metallic-roughness Cook-Torrance lighting (GGX/Smith/Schlick), energy compensation, geometric specular anti-aliasing, and normal mapping. Image-based lighting from HDR environment maps with prefiltered specular and diffuse irradiance convolution. Shadows for all three light types — cascaded shadow maps (up to 4 cascades) for directional lights, plus spot and point (cubemap) shadows, each with hard and PCSS soft-shadow modes.
